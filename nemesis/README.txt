@NAME@ v@VERSION@ — Standalone NEMESIS Package
Package ID: @PACKAGE_ID@

No HMG-API or external hook framework is required!

Install on head unit:
1. Extract this ZIP directly onto the root of a FAT32/exFAT USB drive
   (so NEMESIS.data and packages/@PACKAGE_ID@.zip sit at the USB root).
2. Insert the USB drive into the head unit and confirm the NEMESIS install prompt.
3. Press the physical HOME button to choose Gen5W Theme Launcher as your Home app
   (or open "Gen5W Themes" from NEMESIS / All Apps).
4. Make or browse themes at https://market.ioniqthemes.com or in Gen5W Studio.

Emergency failsafes:
- Place an empty file named REVERT_LAUNCHER.txt or SAFE_MODE.txt inside
  <USB>/Gen5WLauncher/ to immediately revert to the Stock Kia/Hyundai launcher.
